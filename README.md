# 向前一点

这是一个无需注册、依赖和后端的静态网页初版。

## 启动

在此文件夹运行：

```powershell
python -m http.server 4174
```

然后打开 `http://localhost:4174/`。也可直接打开 `index.html`；使用本地 HTTP 地址能获得更稳定的浏览器本地存储行为。

## 数据

目标、任务、专注时段、每日计划和复盘保存在当前浏览器的 `localStorage` 中。不同浏览器配置文件和设备之间不会自动同步；清除网站数据也会删除本地记录。

## 初版范围

- 学期、月份和周目标的层级拆解；周目标可直接添加每日任务。
- 目标和任务均可设置四象限优先级，并在矩阵中查看和调整。
- 今日任务按优先级分组显示，可连续新增、编辑和删除。
- 每日计划时长、任务完成记录。
- 专注与休息计时、专注时段记录、每日和每周复盘。
- 暂无账号、云端备份、跨设备同步、多人共享和应用锁定能力。
